# 🎟️ API EventosTec

Uma robusta API RESTful desenvolvida em **Java** com **Spring Boot** para o gerenciamento de eventos tecnológicos. Projetada para oferecer escalabilidade, segurança e alta performance no processamento de requisições de plataformas de eventos.

## 🚀 Funcionalidades Principais

- **Gerenciamento de Eventos:** Endpoints completos para criação, listagem, atualização e exclusão de eventos tecnológicos.
- **Persistência de Dados:** Integração com banco de dados relacional utilizando Spring Data JPA e Hibernate.
- **Validação de Dados:** Regras rigorosas de integridade utilizando Jakarta Validation.
- **Migrations:** Controle de versão de banco de dados e migrações automatizadas utilizando Flyway.

## 💻 Tecnologias Utilizadas

- **Java**
- **Spring Boot 3** (Web, Data JPA)
- **Flyway** (Database Migrations)
- **Maven** (Gestão de Dependências)
